The high number of measures generated by the analysis of the collected images requires an interface able to order and process them extrapulating statistical information on the identified **Cells**.

To launch the **AMICO_Plotting** macro proceed as before by selecting it in the ImageJ Plugin Menu and select the **.txt** file generated by the **Union** macro
