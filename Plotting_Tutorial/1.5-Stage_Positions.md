Most of the image formats include Metadata also reporting the microscope stage coordinates of the image. The **AMICO_Plotting** macro is able to retrieve  and list them  (at the moment has been extensively tested on .nd2 files generated by the NIS software controlling Nikon instruments) to reposition every single event contained in the selected region in the center of the field of view. The number of displayed cells coincides with the number of elements in the generated list. This repositioning process is the base of the data collection with dynamic resolution employed in the **A.M<sup>3</sup>.I.CO** pipeline (see [**References**](https://github.com/MarioFaretta/A.M3.I.CO/blob/Tutorial/README.md#references)).

Softwares from different microscope manufacturers generate Position Lists with a proprietary format coded in the first lines. Having access to these lists it's possible to modify the output of the generated coordinates to make it compatible with the desired format.

The **Imaging Cut Off Distance** option in the Show Stats menu has been created to introduce a minimal distance in microns between the relocated cells:

<img width="465" height="216" alt="immagine" src="https://github.com/user-attachments/assets/3507fdf2-fa8a-4116-8271-f5e4b2c231e2" />

The rationale is that the relocated cells are targets for a second round of imaging e.g. confocal. Cell neighbours within a certain spatial range can be photobleached. The cut off distance will exclude from the retrieved events the ones lying within the indicated distance thus avoiding the re-acquisition of compromised targets.
