##**Regions**## are a graphical reprensation of a filtering process of numeric values setting parameters ranges that identifies supopulations. They are employed to obtain statistics on a selected ensemble of events as explained in the [**Show Statistics**] () function.
Regions are named with "r" followed by a two-digits index and will appear in the ImageJ ROI Manager. In AMICO, the region constraints are calculated on a graphical base, i.e. on a 0-1024 normalized interval, and are consequently linked to the adopted axis range. This means that the correct procedure to modify a region is the following:
- select the dotplot with the axis corresponding to the target parameters defined by the region
- ensure that the ranges (min-max) coincide with the original ones employed to create the region
- select the region of interest in the ROI manager and modify it
## Region List ##
Regions are stored in an internal **Region List** reporting the interested parameters (X and Y axis), the relative ranges (min-max) and the X and Y arrays of coordinates defining the corresponding ImageJ selections. The window "Region List" containing the tabulated data can be saved as a .csv (remember to insert RL in capital letters in the name of the file). The **Load RL** button allows to load a stored region list in the macro replacing all the elements in the ImageJ ROI manager
