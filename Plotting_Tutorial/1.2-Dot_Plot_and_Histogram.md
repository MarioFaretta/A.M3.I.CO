Dot Plots are commonly employed in Flow Cytometry analysis to graphically represent data:

<img width="1075" height="1125" alt="immagine" src="https://github.com/user-attachments/assets/2e3a45e7-9967-458c-a333-03355c937e18" />

The x, y coordinates of each point in the graph reports the corresponding values of the axis parameters. The color scale is a density distribution going from blue (low) to light gray (high). Next to the main image a second window is opened, reporting the same dot plot on a 32-bit grayscale: here every event is drawn by a Gaussian PSF, summing up overlapping contributions similarly to image formation in the microscope. By adjusting the brighteness and contrast (remember to **Pause** the macro) is possible to obtain different renderings for a better representation.
