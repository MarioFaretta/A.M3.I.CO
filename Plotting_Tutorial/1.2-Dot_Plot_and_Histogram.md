## Dot Plots

Dot Plots are commonly employed in Flow Cytometry analysis to graphically represent data:

<img width="1075" height="1125" alt="immagine" src="https://github.com/user-attachments/assets/2e3a45e7-9967-458c-a333-03355c937e18" />

The x, y coordinates of each point in the graph reports the corresponding values of the axis parameters. The color scale is a density distribution going from blue (low) to light gray (high). Next to the main image a second window is opened, reporting the same dot plot on a 32-bit grayscale: here every event is drawn by a Gaussian PSF, summing up overlapping contributions similarly to the image formation process in the microscope. By adjusting the brightness and contrast (remember to **Pause** the macro) is possible to obtain different renderings for a better representation.

<img width="1132" height="1125" alt="immagine" src="https://github.com/user-attachments/assets/5e8220b9-0d40-4511-84ad-9a3e4e3d775d" />

By selecting the field **N.** in the Y axis with the option to specify a smoothing factor for the histogram.

<img width="951" height="181" alt="immagine" src="https://github.com/user-attachments/assets/f291780d-ca6d-4c72-abf4-fa68827b8f45" />

The resulting curve represents a 1024-bins frequency distribution calculated over the range definied by the minimum and maximum value. The same curve is shown in the ImageJ Plot window ("DNA Hist") originating the data in the Results window. For every cell in the population. the columns show the identificative cell index, the corresponding File Index that identifies the image of origin, the X values normalized to the 0-1024 range ("DATA"), and the original value ("RAW DATA"). This tab can be saved as .csv and/or exported to Excel or any other statistical software to perform additional calculations (e.g. median, quartiles,...) not reported by the macro.

<img width="1716" height="1125" alt="immagine" src="https://github.com/user-attachments/assets/db8df34f-e8a0-425a-a2db-f07ab5343eb3" />

## Dot Plot List

It's possible to create a series (stack) of Dot Plots or histograms with the **DP List** button.

<img width="2000" height="454" alt="immagine" src="https://github.com/user-attachments/assets/415790af-45a7-4f97-9680-2196880e6097" />

By clicking in the corresponding cell of the tab, choose the compartment, the X and Y axis, the corresponding min and max values for the range, the Voltage value and eventually select the gate to be applied. Close the window to continue the process.
