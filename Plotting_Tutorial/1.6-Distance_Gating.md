In image analysis colocalization between signals is usually evaluated on a pixel and on an object base. **AMICO_Plotting** can evaluate relative distances between objects among subcompartmens up to three different species.
By the **Distances** command

<img width="1455" height="836" alt="immagine" src="https://github.com/user-attachments/assets/f80438aa-177e-4967-a48b-89250f34872f" />

it's possible to filter events in the subcompartments according to a **cut-off distance (1)** ) (in pixels): all the objects separated by a value greater than the specified limit will be excluded in both the targeted compartments. In the example the relative position of two different subcompartments is analyzed namely **1: 53BP1** and **2: p53**. Inserting a threshold value of 5 pixels the number of counted and displayed objects undergoes a 3-fold reduction (from 1004 to about 335) as also reported by the comparison of red (no cutoff) and green dots (d=5) in the shown dot plots.

The images generated by the **Show Stats** command will show the effect of this distance gating in the mask of the selected compartment: the gated events will be marked by a filled mask, the excluded by an empty one. Tthe figures display statistics and images related to subcomparment 1: 53BP1 (the effects on the second compartmente can be calculated in an equivalent way by selecting it).
The gating effect will obviusly impact on the number of p53 objects in the second compartment and on the distribution of the corresponing compartment parameters in the cells.

Relative positioning is calculated comparing the Euclidean (centre-to-centre) distances among one element in the first subcompartment and all the others in the second one, and repeating it for every event in the starting ensemble. The number of neighbors within the cutoff distance is then calculated and used to select values greater than 1.

When working with 3 subcompartments the adopted criteria for every event relative distance between all the events must be less than the cutoff value i.e 1 vs 2, 1 vs 3, 2 vs 3.
