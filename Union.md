# AMICO_Union

## Installation

Download Union.txt and copy it into the ImageJ plugin folder. The "_" in the title allows you to see the macro directly in the Plugin Menu. Just select it to run, no compiling required. Union employs the [Convolve 3D] (https://www.optinav.info/download/Convolve_3D.class plugin) from the "Deconvolution" package by Bob Dougherty. Download the package and copy it into the same plugin folder
