# AM<sup>3</sup>ICO_Union

## Installation

Download [AM<sup>3</sup>ICO_Union.txt](https://github.com/MarioFaretta/AMICO/blob/main/AMICO_Union.txt) and copy it into the ImageJ plugin folder. The "_" in the title allows you to see the macro directly in the Plugin Menu. Just select it to run, no compiling required. 
Union employs the [Convolve 3D](https://www.optinav.info/download/Convolve_3D.class) plugin from the "Deconvolution" package by Bob Dougherty and the [Image5D](http://imagejdev.org/plugins/image5d) plugin (including the Image5D Macro language extensions). Download and copy them to the ImageJ/Plugin folder.

## How to use it
### Launch Union
Open ImageJ and from the plugin list launch AM<sup>3</sup>ICO_Union. Select the folder containing the images to be analyzed.
