## Minimum Object-Size
<img width="930" height="714" alt="immagine" src="https://github.com/user-attachments/assets/fa0fdd0d-0ddd-457f-966d-af2d57209da7" />

To define the minimum size for the segmented objects:
- Enter the value in pixels of the area of the smallest cell to be considered (e.g. you can decide to discard cell fragments as micronuclei)
- If you prefer, check the "Get from ROI" option and then draw a region on the targeted smallest object in the image
