All the file formats recognized by the [**Bio-Formats**](https://bio-formats.readthedocs.io/en/stable/) software coded into ImageJ are accepted. Union identifies both multichannel or single-tiff files. Single tiffs  must be properly named to be grouped (e.g. A1--W0001--P0001--C01.tif, P0011--A488.tif) reporting at the end of the name the channel definition preceded by "--".
The last chosen image is used as reference to set the Analysis parameters. Select it with an appropriate number of cells to correctly define them. Select **Exit** to return to the [main window](1-Union.md#launchunion).
