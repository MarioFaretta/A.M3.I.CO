## Whole Cell Analysis

<img width="1265" height="964" alt="immagine" src="https://github.com/user-attachments/assets/1e372d47-d800-4c4b-a58b-9c5c95d4f9e2" />

Whole Cell recognition is based on:
- Delimiting plasma membranes based on a marker: in this case, employing the find maxima command in ImageJ, it's possible to segment the cell borders
  
  <img width="1052" height="1034" alt="immagine" src="https://github.com/user-attachments/assets/0ec1ed78-55c1-43f2-ba2a-a84294b6e26f" />

 <img width="1856" height="834" alt="immagine" src="https://github.com/user-attachments/assets/fa44355f-8c7d-4dae-a794-47ad38c4b3f2" />

  NB the segmented lines in the membrane channel image are  contained in an overlay: by the Image>Overlay>Hide Overlay command on the ImageJ Window you can hide or show (Show Overlay) them to better evaluate the     goodness of the segmentation procedure. 

- Employing nuclei fluorescence to estimate the cell borders, In this case there are two options:
    - Selet the segmentation channel (e.g. segmDAPI) as **Membrane Channel Identifier**
      
    - <img width="1018" height="486" alt="immagine" src="https://github.com/user-attachments/assets/a3c8b8e4-f3ee-461c-88bb-86df6e4737b2" />

    - the Find Maxima procedure is applied to nuclei  by recognizing extension of the particles
  
    - if you check the option **Voronoi-based Cell Recognition**, a simple Voronoi Command is applied to the nuclei mask. With respect to the **Find Maxima** based option, the Voronoi is faster but, in some cases, rawer

Both for Membrane markers or Nuclei inferred limits, it's possible to select the Apply Background option in the mask creation. Even if no background subtraction has been selected, the calculated intensity values for the whole cell in every channel are instead background subtracted. The option is active only for segmentation of the cell borders. 

The **Cytoplasm Channel Identifier** segments cells according to the intensity of the specified channel:

<img width="1235" height="1011" alt="immagine" src="https://github.com/user-attachments/assets/93bb3f47-ea69-4462-97be-e59a029b555d" />

As already specified for the main segmentation threshold, test the various options from the Drop-down menu in the ImageJ Threshold window and then select it in the **Cytoplasm Detection Settings** window, where you can also decide to apply or not background subtracion.

By choosing the **Default** option, it's possible to set a fixed numerical values for the threshold that will be applied to all the images. 

<img width="1376" height="969" alt="immagine" src="https://github.com/user-attachments/assets/3787d195-c633-4da0-afe4-6eba9e73ef3b" />

In the example reported in figure the 478-65535 will be employed for the segmentation.

As mentioned above, this option is valid only for cytoplasm segmentation and not for the cll intensity final calculations.

NB. Cyplasm identification is particularly useful to refine cell borders when membrane segmentation fails. 

<img width="1073" height="1333" alt="immagine" src="https://github.com/user-attachments/assets/730b6bd0-43d3-44fa-8420-dd5e922b5ad8" />

In the example reported in the above figure, cell regions calculated by Nuclei staining expands over empty areas. Thresholding of the cytoplasm correct cell contours in the appropriate way.
