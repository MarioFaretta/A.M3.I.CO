### **RollingBall**
<img width="1034" height="1011" alt="immagine" src="https://github.com/user-attachments/assets/d90f8b17-d6b7-472c-8341-a3f41a8fa5f8" />

The RollingBall algorithm subtracts the average value from moving regions inside the image according to the size of the contained objects.
Choosing a value smaller than the size of the cells will cause uncorrect subtraction with the appearance of vignetting effects inside the objects as reported in the following figure:

<img width="1837" height="857" alt="immagine" src="https://github.com/user-attachments/assets/90b8e457-9ff1-455b-b58f-6b152b49dfad" />

Reenter a new value if the chosen value is not correct till you find the right one i.e. a radius defining circles greated than the largest cell contained throughout the image.

<img width="1841" height="856" alt="immagine" src="https://github.com/user-attachments/assets/e996b8cd-2847-433d-b855-024b8eae3d8d" />

This is one of the parameter to be considered when browsing images in the [Browser](1.1-Browser.md) to select the most convenient reference: choose an image containing a sufficient number of cells with variable dimensions in order to verify the effects of the set parameters.
